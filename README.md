# 流萤 · Claude Code 桌宠

《崩坏：星穹铁道》流萤的像素风桌宠（Windows）。跟随 Claude Code 的工作状态做出反应：思考和用工具时忙碌、需要你授权时招手、出错时沮丧、完成时跳起来等你验收；空闲时眼睛跟着鼠标转，可拖动、可摸头，带经验与等级成长。

精灵表来自 Codex 宠物生成流程（8 列 × 11 行，每格 192×208），用 libimagequant 压成 256 色调色板 PNG（2993KB → 806KB，均方根误差 2.2/255，肉眼几乎无差别），原始无损版保留在本地 `虚拟宠物/outputs/firefly-spritesheet.png`。

## 安装（新电脑）

要求：Windows 10/11（自带 .NET Framework 4.x 即可，不需要 Node）。

在 Claude Code 里依次运行：

```
/plugin marketplace add dxandtom/fire_fly
/plugin install firefly-pet@firefly
```

仓库是私有的，这台电脑的 git 需要能访问 GitHub（首次会弹出登录）。

装好后开一个新会话或发一条消息，流萤就会出现在桌面右下角。右键她 →「开机自启」，以后 Claude 桌面端一打开她就出现、关掉就跟着退出。

## 小功能

- **点她跳回 Claude**：她在招手等你确认、或者任务完成等你验收时，点一下流萤就把 Claude 桌面端窗口切到最前面。
- **任务耗时**：完成时气泡会写上这一轮用了多久，比如「完成啦！（用了 3 分 20 秒）」。
- **全屏时自动隐藏**：看视频、放幻灯片、玩游戏时自动藏起来，退出全屏后回来（右键可关闭）。
- **系统通知**：她被隐藏、被全屏挡住、或者你超过 1 分钟没碰电脑时，需要授权、任务完成、请求失败会弹 Windows 通知；点通知跳回 Claude（右键可关闭）。右键「发一条测试通知」可以马上看看通知能不能弹出来；没弹的话检查 Windows 的通知设置和勿扰模式。
- **卡住提醒**：工作中超过 10 分钟没有任何动静，她会问一句是不是卡住了。
- **多个会话时标出项目**：同时有几个会话在忙时，气泡前会写上项目文件夹名，比如「[虚拟宠物] 需要你确认」。
- **通知中文化**：Claude Code 的英文通知（如 "Claude needs your permission to use Bash"）会翻成中文。
- **像素清晰**：右键勾选后用最近邻缩放，像素边缘更锐利。
- **成就与连续陪伴**：12 个成就（如「一周相伴」连续 7 天一起工作、「夜猫子」凌晨完成任务），在成长手册的「陪伴与成就」里查看。
- **每日总结**：晚上 6 点后第一次摸头或把鼠标放到她身上，她会说今天一起完成了多少任务。

## 等级与解锁

**点流萤脚下的等级徽章**（或右键 →「成长手册」、托盘图标 →「成长手册…」）可以打开成长手册，里面有当前进度、下一个解锁、全部解锁表和经验来源。右键菜单里也会显示「下一个解锁：Lv.x …（还差 N 经验）」。

| 等级 | 累计经验 | 解锁 |
|---|---|---|
| Lv.1 | 0 | 称号「初遇的萤火」 |
| Lv.3 | 100 | 称号「小小同行者」；更多悄悄话 |
| Lv.5 | 280 | **散步模式**（右键勾选开启，空闲时在屏幕底部左右溜达）；青绿色徽章 |
| Lv.6 | 400 | 称号「默契搭档」；更多悄悄话 |
| Lv.8 | 700 | **萤火特效**（每次 Claude 完成任务时飘起萤火，自动生效） |
| Lv.10 | 1080 | 称号「可靠的伙伴」；最后一组悄悄话；金色徽章 |
| Lv.15 | 2380 | 称号「萤火守望者」 |
| Lv.20 | 4180 | 称号「燃烧的萤火」；粉色徽章 |
| Lv.30 | 9280 | 称号「永不熄灭的萤火」 |

第 n 级升到 n+1 级需要 `40 + 20×(n−1)` 经验。经验来源：Claude 完成一次回复 +10、你发一条消息 +3、子代理完成 +2、工具调用成功 +1、摸头 +1（每天最多 20 次）。

## 经验数据

等级和经验保存在 `~/.claude/firefly-pet/stats.json`，不在仓库里。换电脑想保留等级，把这个文件复制到新电脑同一位置即可。

## 工作方式

- `plugins/firefly-pet/hooks/hooks.json`：注册 13 个 Claude Code 事件，每个事件调用 `FireflyPet.exe --hook`，把精简后的事件追加到 `~/.claude/firefly-pet/events.jsonl`。工具调用、子代理、通知等高频事件是异步的（`"async": true`），Claude 不用等它；桌宠按事件发生时间排序，晚到的旧事件不会覆盖新状态。事件文件超过 1MB 时只保留最近 128KB。
- 开会话或发消息时，hook 会把 exe 和素材同步到 `~/.claude/firefly-pet/app/`（固定路径，插件升级后开机自启也不会失效），并在桌宠没运行时启动它。
- `FireflyPet.exe --watch`：开机自启的守护进程，Claude 桌面端从关闭变为打开时拉起桌宠。
- 插件升级后，正在运行的桌宠和守护进程会发现安装目录里有了新版：守护进程立即换新，桌宠等闲下来（没有任务、没在说话、没开手册）再换，不用手动重启。
- 只有 Claude Code（桌面端 Code 标签页或 CLI）会触发 hook；普通聊天时流萤只会陪着你，不会有工作状态动画。

## 修改与发布

```
node build.js        # 编译 src/FireflyPet.cs → plugins/firefly-pet/bin/FireflyPet.exe
```

改完后提交新的 exe，并升级 `plugins/firefly-pet/.claude-plugin/plugin.json` 里的 `version`，其他电脑在 `/plugin` 里更新即可。

调试参数：`--demo` 自动演示全部动作，`--snap <目录>` 每秒把窗口截图存成 PNG，`--data <目录>` 使用另一份数据目录，`--test-hour <0-23>` 让每日总结按指定钟点判断（不用改系统时间）。

## 卸载

`/plugin uninstall firefly-pet@firefly`，再在流萤右键菜单里关掉「开机自启」（或先关掉再卸载）。经验数据在 `~/.claude/firefly-pet/`，不需要的话手动删除。
