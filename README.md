# 流萤 · Claude Code 桌宠

《崩坏：星穹铁道》流萤的像素风桌宠（Windows）。跟随 Claude Code 的工作状态做出反应：思考和用工具时忙碌、需要你授权时招手、出错时沮丧、完成时跳起来等你验收；空闲时眼睛跟着鼠标转，可拖动、可摸头，带经验与等级成长。

精灵表来自 Codex 宠物生成流程（8 列 × 11 行，每格 192×208），用 libimagequant 压成 256 色调色板 PNG（2993KB → 806KB，均方根误差 2.2/255，肉眼几乎无差别），原始无损版保留在本地 `虚拟宠物/outputs/firefly-spritesheet.png`。

## 安装（新电脑）

要求：Windows 10/11（自带 .NET Framework 4.x 即可，不需要 Node）。

在 Claude Code 里依次运行：

```
/plugin marketplace add dxandtom/fire_fly
/plugin install firefly-pet@firefly
```

仓库是私有的，这台电脑的 git 需要能访问 GitHub（首次会弹出登录）。

装好后开一个新会话或发一条消息，流萤就会出现在桌面右下角。右键她 →「开机自启」，以后 Claude 桌面端一打开她就出现、关掉就跟着退出。

## 小功能

- **点她跳回 Claude**：她在招手等你确认、或者任务完成等你验收时，点一下流萤就把 Claude 桌面端窗口切到最前面。
- **完成时报告本轮工作**：完成气泡会写上这一轮用了多久、改了几个文件、跑了几条命令，比如「完成啦！（用了 3 分 20 秒 · 改了 4 个文件 · 跑了 6 条命令）」。
- **会话一览**：同时有 2 个以上会话时，等级徽章右边会出现「N 个会话」（有会话等你确认时变成橙色），点开能看到每个会话的项目、状态和时长，点一行切回 Claude；右键菜单、托盘菜单里也能打开。
- **子代理小萤火**：Claude 派出子代理时，每个子代理对应一颗绕着她转的小萤火（最多 6 颗），跑完就熄灭。
- **休息提醒**：连续用电脑 50 分钟（中间离开不到 5 分钟，锁屏也算离开），她会趁 Claude 在跑长任务时提醒你起来走走；一直没有这种时机，就在 60 分钟时直接提醒，之后最多每 25 分钟一次。提醒后 1 分钟内点她，表示「知道啦」。晚上 11 点到凌晨 5 点还在和 Claude 一起忙，一晚提醒一次早点睡。可在右键「提醒与声音」里关闭。
- **甩出去**：拖着她快速一甩再松手，她会飞出去、弹一下落到屏幕底部；慢慢放下就停在原地。
- **纪念日**：认识第 7、30、100、200、365… 天时，她会庆祝一下。
- **跟着工具调用打节拍**：Claude 每调用一次工具，她的工作动作就快一拍，手边蹦出一颗小光点，忙起来像在跟着节奏敲键盘。
- **测试和编译有反应**：Claude 跑测试或编译（如 `pytest`、`npm test`、`go test`、`node build.js`、`cargo build`、`make`）时，通过了她会跳一下、撒一把彩色萤火；没过她会着急一下。只看命令本身和成败，不看输出内容。
- **离开打盹、回来迎接**：你离开电脑 5 分钟以上，她会冒出 Zzz 打盹；你一回来她就招手，告诉你离开了多久，以及这段时间 Claude 完成了几个任务。
- **节日特效**：春节（除夕到初三）、元宵、端午、七夕、中秋按农历自动识别，加上元旦、情人节、万圣节、平安夜、圣诞、跨年。当天第一次见到你时说一句祝福，平时飘雪、飘爱心、放烟花、升灯笼。右键「提醒、声音与节日 → 我的生日…」设好生日，那天她专门给你放烟花。可以在同一个菜单里关掉节日特效。
- **上下文快满提醒**：每次 Claude 回复完，她看一眼这个会话的上下文用了多少；右键「会话一览」里也会标出每个会话的上下文用量。用量只读会话记录末尾那条回复里记的 token 数，不读聊天内容。用到 80% 时她提醒你可以 `/compact` 或开新会话。窗口大小按 200K 算，已经超过 200K 的会话按 1M 算。会话一览里每个会话也标着上下文百分比。右键「会话上下文快满时提醒」可以关掉。
- **陪她玩**：右键「陪她玩」里有：
  - **扔个光球给她**：光球会弹跳、滚动，她跑过去接住，+1 经验。你也可以按住光球甩出去，她照样去追。
  - **接萤火小游戏**：30 秒内萤火从屏幕上方落下，按住她左右拖去接。金色 +1 分，红色是 bug，-2 分。结束时报分并记录最高分，破纪录放烟花，每 3 分 +1 经验。
  - 玩耍得的经验每天最多 10 点。
- **自定义台词**：右键「陪她玩 → 编辑我的台词…」会用记事本打开 `~/.claude/firefly-pet/lines.txt`，在 `[摸头]`、`[完成]`、`[连戳]` 下面每行写一句。保存后几秒内生效，你写的和自带的各占一半机会。
- **连戳会躲开**：2.5 秒内连点她 5 下，她嘟囔一句，往远离鼠标的方向跑开。
- **提示音**：右键「提醒、声音与节日 → 提示音」开启后，等你确认时轻响一声（默认关闭）。
- **全屏时自动隐藏**：看视频、放幻灯片、玩游戏时自动藏起来，退出全屏后回来（右键可关闭）。
- **系统通知**：她被隐藏、被全屏挡住、或者你超过 1 分钟没碰电脑时，需要授权、任务完成、请求失败会弹 Windows 通知；点通知跳回 Claude（右键可关闭）。右键「提醒与声音 → 发一条测试通知」可以马上看看通知能不能弹出来；没弹的话检查 Windows 的通知设置和勿扰模式。
- **卡住提醒**：工作中超过 10 分钟没有任何动静，她会问一句是不是卡住了。
- **多个会话时标出项目**：同时有几个会话在忙时，气泡前会写上项目文件夹名，比如「[虚拟宠物] 需要你确认」。
- **通知中文化**：Claude Code 的英文通知（如 "Claude needs your permission to use Bash"）会翻成中文。
- **像素清晰**：右键勾选后用最近邻缩放，像素边缘更锐利。
- **成就与连续陪伴**：12 个成就（如「一周相伴」连续 7 天一起工作、「夜猫子」凌晨完成任务），在成长手册的「陪伴与成就」里查看。
- **每日总结**：晚上 6 点后第一次摸头，她会说今天一起完成了多少任务（每天一次；鼠标只是经过不会触发）。
- **和 Claude 一起的时长**：Claude 桌面端在前台、并且你 2 分钟内动过电脑时计时，聊天和 Code 标签页都算（只看前台窗口属于哪个程序，不读任何聊天内容；锁屏、离开不算）。每满 10 分钟 +2 经验，每天最多算 2 小时。只聊天的日子晚上也会有每日总结。在终端或编辑器（Windows Terminal、PowerShell、VS Code、JetBrains 等）里用 Claude Code CLI 时，只要它 3 分钟内有动静（发消息、调用工具）也计入。
- **陪伴报告**：右键「陪伴报告」、托盘菜单、或成长手册「最近 7 天」下方的链接，随时查看今天、本周、本月、今年：完成任务、发出消息、调用工具、一起工作的天数，和上一期对比、最忙的一天，以及按天/按月的柱状图。按天的记录从 v1.4.0 开始保存，最多保留 400 天。
- **最近 7 天**：成长手册里画出最近 7 天每天一起完成的任务数。

## 等级与解锁

**点流萤脚下的等级徽章**（或右键 →「成长手册」、托盘图标 →「成长手册…」）可以打开成长手册，里面有当前进度、下一个解锁、全部解锁表和经验来源。右键菜单里也会显示「下一个解锁：Lv.x …（还差 N 经验）」。

| 等级 | 累计经验 | 解锁 |
|---|---|---|
| Lv.1 | 0 | 称号「初遇的萤火」 |
| Lv.3 | 100 | 称号「小小同行者」；更多悄悄话 |
| Lv.5 | 280 | **散步模式**（右键勾选开启，空闲时在屏幕底部左右溜达）；青绿色徽章 |
| Lv.6 | 400 | 称号「默契搭档」；更多悄悄话 |
| Lv.8 | 700 | **萤火特效**（每次 Claude 完成任务时飘起萤火，自动生效） |
| Lv.10 | 1080 | 称号「可靠的伙伴」；最后一组悄悄话；金色徽章 |
| Lv.12 | 1540 | **收藏品**（Claude 完成任务时有机会送你一件小礼物，任务越久机会越大；共 12 件，分普通、稀有、珍贵，在成长手册里收集） |
| Lv.15 | 2380 | 称号「萤火守望者」；**坐在窗口上**（右键勾选开启：跳到你正在用的窗口顶边坐着，窗口移动她跟着；最大化、全屏的窗口没地方坐，她就回原位；把她拖开就不再坐那个窗口） |
| Lv.20 | 4180 | 称号「燃烧的萤火」；粉色徽章；**夜光**（晚上 7 点到早上 6 点身后亮起柔和的萤光，自动生效） |
| Lv.30 | 9280 | 称号「永不熄灭的萤火」 |

第 n 级升到 n+1 级需要 `40 + 20×(n−1)` 经验。经验来源：Claude 完成一次回复 +10、你发一条消息 +3、子代理完成 +2、工具调用成功 +1、摸头 +1（每天最多 20 次）、和 Claude 一起待 10 分钟 +2（每天最多算 2 小时）。

## 经验数据

等级和经验保存在 `~/.claude/firefly-pet/stats.json`，不在仓库里。换电脑想保留等级，把这个文件复制到新电脑同一位置即可。

## 工作方式

- `plugins/firefly-pet/hooks/hooks.json`：注册 13 个 Claude Code 事件，每个事件调用 `FireflyPet.exe --hook`，把精简后的事件追加到 `~/.claude/firefly-pet/events.jsonl`。除了会话结束，其余事件都是异步的（`"async": true`，v1.5.0 起），Claude 不用等它；hook 用自带的小 JSON 解析器，不加载 .NET 的 JavaScriptSerializer，单次约 45ms（v1.4.5 约 85ms）；桌宠按事件发生时间排序，晚到的旧事件不会覆盖新状态。事件文件超过 1MB 时只保留最近 128KB。
- 开会话或发消息时，hook 会把 exe 和素材同步到 `~/.claude/firefly-pet/app/`（固定路径，插件升级后开机自启也不会失效），并在桌宠没运行时启动它。安装目录里已经是更新的版本时不会被覆盖（v1.4.5 起；插件升级后没重启的旧会话还在用旧版 hook，v1.4.4 及以前会把它换回旧版）。
- `FireflyPet.exe --watch`：开机自启的守护进程，Claude 桌面端从关闭变为打开时拉起桌宠。
- 插件升级后，正在运行的桌宠和守护进程会发现安装目录里有了新版：守护进程立即换新，桌宠等闲下来（没有任务、没在说话、没开手册）再换，不用手动重启。内存占用超过 300MB 时（正常到不了，保底用），桌宠也会这样趁空闲换一个新进程。
- `FireflyPet.exe --quit`：让正在运行的桌宠和守护进程存好数据后退出（最多等 10 秒）。桌宠是工具窗口，收不到系统的关闭消息，重启、卸载前用它代替强制结束。
- 统计数据先完整写进 `.tmp` 再原子替换，上一份留作 `.bak`；文件损坏或保存被打断时，启动会自动用 `.bak`/`.tmp` 恢复，坏文件另存为 `.broken`，不会从 0 级重来。
- 内存：桌宠用软件渲染。透明窗口走显卡渲染时，每帧从显存读回再贴到桌面的那条路径会漏内存（萤火、气泡渐变、夜光时每分钟 5～27MB，v1.4.2 连开 15 小时到了 470MB）；软件渲染不漏，启动内存从约 160MB 降到约 80MB，CPU 也更低。
- 省电：她被藏起来（手动隐藏或全屏时）画面停止刷新；人离开 5 分钟以上降到每秒 4 帧。判断 Claude 桌面端是否在运行时，只确认上次找到的进程还在不在，不再每 3 秒扫一遍所有进程。
- 只有 Claude Code（桌面端 Code 标签页或 CLI）会触发 hook；普通聊天时流萤只会陪着你，不会有工作状态动画。

## 修改与发布

```
node build.js        # 编译 src/FireflyPet.cs → plugins/firefly-pet/bin/FireflyPet.exe
```

改完后提交新的 exe，并升级 `plugins/firefly-pet/.claude-plugin/plugin.json` 里的 `version`，其他电脑在 `/plugin` 里更新即可。

测试（`tests/`，都只用临时数据目录，不碰真实数据；用 `powershell -NoProfile -STA -File tests\<脚本>.ps1` 运行）：

- `t_hook.py`（`python tests/t_hook.py`）：hook 耗时、事件字段、中文和转义、测试/编译命令识别、退出码、Stop 和 SessionStart 带会话记录路径。
- `t_play.ps1`：台词文件解析、自定义台词生效、连戳躲开、上下文用量读取（截断的超长行、子代理行、聊天内容里的假数字）、会话一览标注和快满提醒、扔光球到接住、小游戏计分与最高分、玩耍经验上限、隐藏和关闭时收回小窗口。
- `t_fun.ps1`：节日日期（含闰月的年份）、打节拍、测试结果反应、离开打盹与回来迎接、节日祝福与特效、生日、光点清理。
- `t_safety.ps1`：统计文件的原子保存、备份恢复，桌面端进程检测的结果和耗时。
- `t_time.ps1`：和 Claude 一起的时长：计时、间隔过滤、每日经验上限、只聊天的每日总结、换日。
- `t_frames.ps1`：动画帧是独立位图，像素和从精灵表直接裁剪的结果逐字节一致；气泡淡入、飞出萤火时界面上没有半透明（Opacity）元素。
- `t_report.ps1`：陪伴报告四个时段、窗口复用、悬停不消耗每日总结、会话一览关闭。
- `mem_host.cs`：内存增长测量。用系统自带的 csc 编译后，在临时目录里加载一只测试桌宠，每 15 秒记一次私有内存并输出斜率（用 PowerShell 当宿主测不准，它自己每分钟就涨好几 MB）。模式里 `festive` 是节日飘雪 + 打节拍 + 彩色萤火一起开，`play` 是每 6 秒扔光球、每 40 秒开一局小游戏。模式后加 `-sw` 用软件渲染（和桌宠一致），不加就是显卡渲染，可以复现泄漏。编译和用法见文件开头。

调试参数：`--demo` 自动演示全部动作，`--snap <目录>` 每秒把窗口截图存成 PNG，`--data <目录>` 使用另一份数据目录，`--test-hour <0-23>` 让每日总结按指定钟点判断，`--test-date <yyyy-MM-dd>` 让节日按指定日期判断（都不用改系统时间）。

## 卸载

`/plugin uninstall firefly-pet@firefly`，再在流萤右键菜单里关掉「开机自启」（或先关掉再卸载）。运行 `~/.claude/firefly-pet/app/FireflyPet.exe --quit` 可以让桌宠和守护进程马上退出。经验数据在 `~/.claude/firefly-pet/`，不需要的话手动删除。
